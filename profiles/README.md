# Optional Technology Profiles

These profiles are intentionally outside the generic core catalog. They add
technology-specific detection hints and implementation-oriented mappings for
selected ecosystems.

The profiles in this folder are not registered in `catalog.yaml` and do not
change the meaning of the generic core rules. They only help specialized
tooling or AI agents translate generic rules into language- or
framework-specific review heuristics.

Current profile scaffolding:

- `java/`
- `java-quarkus/`
- `java-spring-boot/`
